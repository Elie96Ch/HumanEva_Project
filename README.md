# HumanEva Project

This repository contains preprocessing, MATLAB export, and PyTorch baseline experiments for lightweight monocular 3D human pose estimation using the HumanEva dataset.

## Current status
- HumanEva body pose exported from MATLAB support code
- Python dataset loader working
- MLP baseline trained on 2D-to-3D body pose lifting

## Main folders
- `scripts/` : runnable scripts
- `src/` : reusable Python modules
- `matlab/` : MATLAB export scripts
- `data/` : local dataset storage (ignored by git)
- `outputs/` : experiment outputs (ignored by git)
